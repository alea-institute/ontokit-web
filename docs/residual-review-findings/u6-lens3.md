The compose binds API/web to all IPv4/IPv6 interfaces, while all recorded 401 verification is against the hostname route; no firewall evidence is supplied (`.worker-reports/u6-evidence/dev-infra-compose-and-env.txt:63-67,120-124,138-141`; `docs/roundup-2026-08/DEV-UAT-LOG.md:69-77,140-149`). Bind to a private interface/localhost or document and verify the host/provider firewall before claiming KTD2/DoD full-window coverage (`docs/plans/2026-08-08-001-feat-ontokit-roundup-execution-plan.md:102,341`).

[P2] KD1 ratifies two helpers without independent evidence that they deliver contributor-author/bot-committer attribution or correct credential selection. The bundle only proves call sites for `commit_identity.resolve`; it omits both helper implementations, tests, mirror routing, and an attributed merge commit (`.worker-reports/u6-evidence/api-fixround-code.diff:1419-1421,1579-1590`; `docs/roundup-2026-08/DEV-UAT-LOG.md:124-129`). Preserve U5's explicit git-log test as the ratification gate (`docs/plans/2026-08-08-001-feat-ontokit-roundup-execution-plan.md:206-212`).

[P2] The DEV infrastructure standup had no written product requirement when built and remains hand-rolled. The plan acknowledges the execution cascade ran ahead of the harness and only retroactively introduces R13/U12 (`docs/plans/2026-08-08-001-feat-ontokit-roundup-execution-plan.md:36-40,62,266-271`). This is the anti-ratification finding required by U6 itself (`docs/plans/2026-08-08-001-feat-ontokit-roundup-execution-plan.md:214-220`); it closes only when committed IaC matches the running server and the ad-hoc state is retired (`docs/plans/2026-08-08-001-feat-ontokit-roundup-execution-plan.md:343`).

R6 enumerates “fix rounds 1–3, DEV infra standup,” while U6's Goal/Approach expands the reviewed scope to “deploy configuration” (`docs/plans/2026-08-08-001-feat-ontokit-roundup-execution-plan.md:49,214-219`). ## Plan-absorption errors

1. **R6 under-records its own scope.** U6 includes deploy configuration and a fifth security-posture lens, but R6 names neither (`docs/plans/2026-08-08-001-feat-ontokit-roundup-execution-plan.md:49,214-220`).
2. **KTD2/DoD overstate the historical gate.** The plan says the auth-disabled service “MUST sit behind” Traefik and later requires proof it was network-gated for the full duration, but the captured compose publishes bypass ports and the evidence tests only the hostname (`docs/plans/2026-08-08-001-feat-ontokit-roundup-execution-plan.md:102,341`; `.worker-reports/u6-evidence/dev-infra-compose-and-env.txt:138-141`; `docs/roundup-2026-08/DEV-UAT-LOG.md:69-77`). The plan should distinguish “hostname gated” from “all ingress paths gated” until firewall evidence exists.
3. **The Traefik assumption missed route multiplicity and stale deployment ownership.** F6 is not evidence against the final KD4 placement—the stale triad was stopped—but it is evidence that wildcard-fronting alone does not guarantee which deployment answers (`docs/plans/2026-08-08-001-feat-ontokit-roundup-execution-plan.md:80,118`; `docs/roundup-2026-08/DEV-UAT-LOG.md:98-114,140-147`).
4. **KD1 is recorded more confidently than its evidence permits.** “Ratifies ... as built” accurately records a decision, but the supplied record does not show `mirror_credential.py` at all or an attributed merge; U5 is the first contract that supplies a real ratification test (`docs/plans/2026-08-08-001-feat-ontokit-roundup-execution-plan.md:77,206-212`; `.worker-reports/u6-evidence/api-fixround-code.diff:1419-1421,1579-1590`).

## Verdict

The pre-plan fix rounds align with and now satisfy R2, R3, and KTD8, and they provide partial evidence toward R1/R4. KD4 correctly absorbs the observed CPX41/hetzner-dev topology after F6's stale-route correction, but it does not ratify auto-deploy, promotion, AWS PROD, or the picker. The largest remaining contract violation is infrastructural: DEV is still hand-rolled (R13), and the captured direct port bindings leave KTD2's full-surface auth gate unproven and potentially bypassable. KD1 likewise remains a decision awaiting independent attribution and credential-routing evidence. Accordingly, Lens 3 does **not** clear the built work as fully aligned: it is conditionally aligned with one P1 exposure finding, three P2 traceability/IaC findings, and material DoD work still outstanding (`docs/plans/2026-08-08-001-feat-ontokit-roundup-execution-plan.md:337-345`).
